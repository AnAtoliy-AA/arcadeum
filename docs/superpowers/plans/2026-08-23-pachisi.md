# Pachisi (ARC-886) — Implementation Plan

Branch `ARC-886-pachisi` off `origin/develop`. Reference: backgammon (dice
phases, BaseGameService/BaseGameGateway) + hearts/spades (recent catalog &
create-page wiring).

## BE (`apps/be`)

1. `src/games/engines/pachisi/`
   - `pachisi.constants.ts` — MIN/MAX_PLAYERS (2/4), SEAT colors/offsets,
     RULE_VARIANTS `['standard','quick']`, TOKENS_BY_RULE_VARIANT,
     GAME_PHASE, ACTION, DEFAULT_OPTIONS.
   - `pachisi.types.ts` — State/Player/Token/payloads; `logs: GameLogEntry[]`.
   - `pachisi.utils.ts` — TRACK_COORDS table, seat assignment, safe cells,
     getAllLegalMoves(playerId, state), applyMoveToTokens (pure).
   - `pachisi.validators.ts` — roll/move/pass/forfeit validators.
   - `pachisi.engine.ts` — extends `BaseGameEngine`; injected DiceRoller.
2. Register engine in `engines/engines.module.ts`.
3. `src/games/pachisi/pachisi.service.ts` (extends `BaseGameService`),
   `src/games/pachisi/pachisi-bot.service.ts` (difficulty tiers + watchdog
   loop like backgammon bot incl. AI-vs-AI delay helper).
4. `src/games/pachisi.gateway.ts` — sibling file; prefix `pachisi`;
   handlers `.session.roll` / `.session.move`.
5. Wire into `games.module.ts` providers.
6. Catalog entry in `games.catalog.ts`: modes `['standard','quick']`,
   variants `[...SHARED_VISUAL_THEMES]`, rules idle/spectators.
7. Add `'pachisi_v1'` to `common/ai-vs-ai.ts` supported list (+ factory if
   required there).
